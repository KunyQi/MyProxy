# 常见问题

### MyProxy 是一个 VPN 服务吗？

不是。MyProxy 是一套软件，不是服务。你需要用自己的服务器部署它，再把客户端交给要用的人。仓库里不提供任何共享服务器、账号或安装包，文档里出现的示例地址也都只是占位。

### 它和直接使用 Xray 客户端有什么不同？

Xray 本身功能强大，但直接使用时，每个人都要自己导入并理解连接配置。MyProxy 把配置交给部署者统一管理，使用者只看到一个配对码和一个开关。它还提供了按设备发放的凭据、随时撤销设备的能力和按类别聚合的用量统计，管理一群人的使用会轻松很多。

### 支持哪些协议？

目前只支持 Xray 的 VLESS + REALITY。服务端只接受 REALITY 类型的入站，其他类型会被拒绝。

### 我的所有流量都会经过服务器吗？

取决于连接模式。默认的智能分流下，国内网站直连，不经过你的服务器，其余流量走代理；全局代理模式下，所有网站都走代理。两种模式都会阻断私网地址和 BT 流量。

### 服务器会记录我的什么信息？

控制面记录账号、设备，以及按类别聚合的用量。管理后台可以看到设备的出口地址，这些记录保留多久由部署者配置。控制面本身不转发代理流量；走代理的流量由同一台服务器上的 Xray 承载，因此服务器的管理者需要值得信任，这也是“自建”的意义所在。

### 自建就一定更安全、更私密吗？

自建减少了对第三方 VPN 服务商的信任，但不能自动保证隐私。服务器被入侵、凭据泄露、设备本身不安全，或者路由配置有误，都会影响隐私。保持系统补丁、证书和凭据的妥善管理，和选择自建同样重要。

### 配对码丢了或者过期了怎么办？

配对码默认一小时内有效，管理员也可以设成一天或七天；生成之后，后台不会再显示它的明文。丢失或过期都没关系，请管理员重新生成一个就好。

### 设备丢了怎么办？

请管理员在后台撤销这台设备。被撤销的设备无法再取得连接配置；如果之后找回来了，需要新的配对码才能重新绑定。

### 客户端会自动更新吗？

不会自动安装。新安装的客户端默认不检查更新；即使打开了检查，更新也必须通过部署者密钥的签名和摘要校验，并且由你确认后才会安装。部署者没有配置自己的信任密钥时，客户端会拒绝任何更新。

### 支持哪些系统？

Windows、Android 和 Linux。Android 已经通过实机测试，不同设备和系统版本的兼容性需要分别确认；Windows 和 Linux 有构建与回归测试。Linux 的托盘和系统代理行为依赖桌面环境，GNOME、KDE 下的完整体验需要在目标桌面上验收。

### 有现成的安装包可以下载吗？

没有。安装包里需要带上你自己的服务器地址，所以必须由部署者自己构建、签名和分发。仓库提供了一个[三端下载页模板](../../server/deploy/downloads/index.html)，部署者可以拿来为使用者搭一个下载页。

### 发现了安全问题，怎么报告？

请不要在公开的 Issue 或讨论区发布漏洞细节。在 GitHub 仓库的 Security 页面创建私有报告即可，具体要求见[安全政策](../../SECURITY.md)。

### 我可以参与开发吗？

欢迎。从[参与 MyProxy](../../CONTRIBUTING.md)开始，那里列出了上手要读的文档、改动后需要运行的检查，以及提交与审查的要求。
