# 本机浏览器管理入口

发布向导的浏览器加密功能需要安全上下文。管理后台通过受限 SSH 隧道提供自签 HTTPS 时，可以用 `deploy/admin_browser_bridge.py` 在本机提供 `http://127.0.0.1` 入口；现代浏览器将 HTTP loopback 视为安全上下文，无需将后端自签证书加入系统信任。

先使用已有的受限管理启动器建立 SSH 隧道，确认其本机 HTTPS 端口仍在监听。桥接工具不会创建隧道，也不会在退出时关闭已有的 SSH 进程。SSH 身份必须有执行 `token` 命令的权限，并使用已经核验的 `known_hosts`。

准备通过可信部署记录核验的后端叶证书 **DER 字节 SHA-256**，共 64 个十六进制字符。不要根据一次未经校验的连接自动接受或更新指纹。每次桥接连接会先校验该指纹，再发送 HTTP 请求、会话信息或安装包；证书更换时需先独立核验新指纹。

替换下面示例中的主机、文件路径、既有隧道端口和可信指纹后运行：

```powershell
python server/deploy/admin_browser_bridge.py --host server.example --ssh-user myproxy-admin --ssh-key C:/keys/admin_ed25519 --known-hosts C:/keys/known_hosts --upstream-port 31820 --tls-sha256 "已核验的64位十六进制指纹"
```

工具默认选择空闲端口，只监听 `127.0.0.1`，输出带一次性登录票据片段的本机 URL，并打开默认浏览器。`--listen-port 32100` 可固定端口；`--no-browser` 仅输出入口，适合由已有启动器或浏览器自动化打开。不要将该入口转发到其他机器，也不要分享带票据的 URL。登录页会在网络请求前清除票据片段。

工具仅执行一次受限 SSH `token` 命令，将其输出在内存中换成短期一次性 UI 票据。不会记录、保存或输出管理员 Bearer，也不会将它注入后续浏览器请求；登录后使用浏览器取得的管理会话。无会话的请求仍由后端按匿名请求处理。

只有管理页面、同源静态资源、会话、`/api/admin/*` 和健康检查路径可经桥接访问。工具拒绝外部 Origin、不同 Host、异常路径和模糊请求体边界，上传上限为 512 MiB，并逐块转发。后端 CSP 和安全响应头保持原值。按 `Ctrl+C` 停止桥接；如提示连接失败，应检查既有隧道、受限 SSH 身份、`known_hosts` 和可信指纹。
